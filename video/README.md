# لستَ جاهزًا — فيديو عمودي 9:16

- `lastu-jahizan.mp4` — الفيديو النهائي (1080×1920، 30fps، 35 ثانية، H.264 + AAC)
- `src/` — سكربتات الإنتاج:
  1. `prep.py` — قصّ لقطات الـ storyboard، إزالة النصوص المطبوعة والتوقيتات، وتكبير ×4 (EDSR)
  2. `fix.py` — ترقيع أماكن التوقيت وزر التشغيل
  3. `tts.py` — التعليق الصوتي (صوت رجل عربي عميق، edge-tts `ar-SA-HamedNeural`)
  4. `music.py` — بيانو هادئ مُولَّد (Am → C) يعلو عند «لا تلتفت للعمر» وينخفض في الخاتمة
  5. `render.py` — حركة الكاميرا، تدرّج الألوان من الأزرق البارد إلى الذهبي، ونصوص Cairo Bold بتأثير Fade
