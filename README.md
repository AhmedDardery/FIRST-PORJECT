# إبريز العربية — بتصميم روشن

موقع تعريفي لشركة **إبريز العربية** ([ebreezarabian.com](https://ebreezarabian.com/ar/)) مبني على نظام التصميم المستخرج من **[roshn.sa](https://www.roshn.sa/ar)** باستخدام أداة [dembrandt](https://github.com/dembrandt/dembrandt).

## التشغيل

موقع ثابت (HTML/CSS/JS) بدون أي بناء:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

أو افتح `index.html` مباشرة، أو ارفعه على GitHub Pages / Netlify / Hostinger.

## البنية

```
index.html              الصفحة الرئيسية (عربي RTL)
assets/css/style.css    التنسيق — المتغيرات في :root مأخوذة من مخرجات dembrandt
assets/js/main.js       السلايدر، تبويبات المحفظة، بطاقات الخدمات، العدادات
assets/img/             صور وشعار إبريز العربية
design-tokens/roshn/    مخرجات dembrandt الخام (JSON و DESIGN.md و Tailwind theme)
```

## ما أُخذ من تصميم روشن

| العنصر | القيمة المستخرجة |
|---|---|
| اللون الأساسي | `#006450` (hover `#005040`) |
| خلفية الهيرو | `#02231f` |
| الأسطح | `#FAFAFA` · `#EBFEF7` |
| النص | `#11100F` · `#383731` · الحدود `#B0AFA5` |
| الخط | IBM Plex Sans Arabic، أوزان خفيفة 200–300 للعناوين الكبيرة |
| الأزرار | كبسولة `9999px` + دائرة سهم منفصلة |
| الحواف | `6px` للبطاقات والصور |
| الحركة | `cubic-bezier(0.4, 0, 0.2, 1)` بمدد 0.3 / 0.5 / 0.7 ثانية |

والأقسام تحاكي ترتيب روشن: شريط تنقل زجاجي عائم ← هيرو داكن بعنوان ضخم ← «عن الشركة» مع صور متداخلة وأرقام ← عرض المشاريع بملء الشاشة مع شريط جانبي ← قسم «حدّد اهتمامك» (هنا: الخدمات) ← دعوة «سجّل اهتمامك» ← تذييل بأعمدة.

## إعادة الاستخراج

```bash
npx dembrandt https://www.roshn.sa/ar --save-output --design-md --tailwind --slow
```

> المحتوى والصور ملك إبريز العربية. الأرقام التشغيلية تقريبية والصور تخيلية كما في الموقع الأصلي.
